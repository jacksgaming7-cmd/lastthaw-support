# Last Thaw — Support

Support site for **Last Thaw** on Steam (App ID `5378590`), by TAH Games.

**Live page:** https://jacksgaming7-cmd.github.io/lastthaw-support/

This repository exists so the game has a public support URL, a privacy policy and a public place to file bugs. It does
**not** contain the game's source.

## Getting help

- **Something broken?** [Open an issue](../../issues/new). Please include what you were doing and the newest file from
  `%APPDATA%\TAH Games\Last Thaw\logs\`.
- **Anything else:** <tahgames.support@gmail.com>
- **Refunds** are handled by [Steam Support](https://help.steampowered.com/), not by us.

## Repository layout

```
index.html     the support page (plain HTML + CSS, no build step)
privacy.html   the privacy policy
logo.png       game logo
bg.jpg         header background
```

Published with GitHub Pages from the `main` branch, root folder. Editing a page and pushing is all it takes to update
the live site.
